Exercises Services¶

class ExerciseService[source]¶

Bases: CompositeServiceMixin, SQLAlchemyAsyncRepositoryService[Exercise, Any]

Handles database operations for exercises.

Composes catalog services (muscle groups, equipment, tags) via CompositeServiceMixin; composed services share the parent’s session.

async update(data: ModelDictT[m.Exercise], item_id: Any | None = None, *, attribute_names: Iterable[str] | None = None, with_for_update: ForUpdateParameter = None, auto_commit: bool | None = None, auto_expunge: bool | None = None, auto_refresh: bool | None = None, id_attribute: str | InstrumentedAttribute[Any] | None = None, error_messages: ErrorMessages | EmptyType | None = <class 'advanced_alchemy.utils.dataclass.Empty'>, load: LoadSpec | None = None, execution_options: dict[str, Any] | None = None, uniquify: bool | None = None, bind_group: str | None = None, schema_dump_config: SchemaDumpConfig | None = None) → m.Exercise[source]¶

Update exercise with role-aware junction merge for muscle lists.

Advanced Alchemy’s update() has no partial-collection contract: a collection key in the payload replaces the whole relationship, and the junction’s muscle_role cannot be expressed by plain assignment — muscle keys are popped here and merged object-aware (see _merge_exercise_muscles).

auto_commit is accepted for interface compatibility but never honored: this method relies on the outer session lifecycle to commit, so the junction merge shares one transaction with the scalar update. schema_dump_config is not forwarded — the payload is normalized to a dict before persistence.

Raises:

  • NotFoundException – If a referenced muscle group, equipment, or tag id does not exist.

  • ConflictException – If the same muscle group is listed as both primary and secondary.

  • DuplicateKeyError – If the resulting slug conflicts with an existing exercise.

async delete_exercise(exercise_id: UUID, user_auth: UserAuth) → None[source]¶

Delete an exercise after checking access permissions.

Deletion relies on the outer session lifecycle to commit, same as update(): session.delete() only stages the deletion, and the DELETE is issued during the flush triggered by the outer commit().

Raises:

  • NotFoundException – If the exercise is not found.

  • PermissionDeniedException – If the user lacks permission to delete the exercise.

async get_exercises_paginated_dto(params: ExerciseFilters, user_id: UUID) → OffsetPagination[ExerciseRead][source]¶

Provide filtered and paginated list of exercises with caching.

async get_by_name(user_id: UUID, scope: Literal[ExerciseScope.USER, ExerciseScope.SYSTEM], name: str) → m.Exercise[source]¶

Retrieve user-defined or system exercise by name.

The name is normalized to a slug before lookup, so names that normalize to the same slug resolve to the same exercise.

The scope determines the search space: USER searches exercises created by user_id; SYSTEM searches system defaults and ignores user_id.

Raises:

NotFoundException – If no exercise matches the normalized name in the given scope.
