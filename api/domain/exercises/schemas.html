class ExerciseScope(*values)[source]¶

Bases: StrEnum

Defines the visibility and ownership scope of an exercise.

Used to filter system exercises, user-created exercises, or both.

SYSTEM = 'system'¶
USER = 'user'¶
ALL = 'all'¶
app.domain.exercises.schemas.CdnRelativePath = Annotated[str, Field(...)]¶

Annotated str type constraining relative CDN image paths: leading /, format /{exercise-directory}/{filename}.{ext} with a jpe?g/png/webp extension, max 512 characters. Join rule: CDN_BASE_URL.rstrip('/') + path.
