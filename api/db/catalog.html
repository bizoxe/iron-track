Catalog Models¶

Reference entities for exercise categorization (muscle groups, equipment, and tags), plus the association objects and tables linking them to exercises.

Association Object¶

class ExerciseMuscle(**kwargs)[source]¶

Bases: DefaultBase

Exercise muscle targeting.

One muscle group in one role for one exercise (PK excludes the role: the same muscle cannot be both primary and secondary).

exercise_id: Mapped[UUID]¶

Referenced exercise ID.

muscle_group_id: Mapped[int]¶

Referenced muscle group ID.

muscle_role: Mapped[MuscleRole]¶

Targeting role of the muscle group in the exercise.

exercise: Mapped[Exercise]¶

The exercise this muscle targeting belongs to.

muscle_group: Mapped[MuscleGroup]¶

Targeted muscle group.

Association Tables¶

exercise_equipment¶

Association table linking exercise to the required equipment.

exercise_tag¶

Association table linking exercise to system-defined metadata tags.
