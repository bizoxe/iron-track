Database Enums¶

Database binding of the domain vocabulary.

Defines physical enum names, DDL, and column types for app.domain.enums.

enum_type_name(enum_cls: type[StrEnum]) → str[source]¶

Return the PostgreSQL enum type name.

enum_values(enum_cls: type[StrEnum]) → list[str][source]¶

values_callable for pg.ENUM: persist .value labels, not member names.

pg_enum(cls: type[E]) → sqlalchemy.dialects.postgresql.named_types.ENUM[source]¶

Return a PostgreSQL enum column type without creating the database type.

iter_enum_type_ddl() → Iterator[str][source]¶

Yield one CREATE TYPE statement per registered enum.

drop_enum_types_ddl() → str[source]¶

Return one DROP TYPE statement for all registered enums.
